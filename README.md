# test_name
This project was created solely for educational purposes. Its purpose is to display my name.

## Project Description
This training project demonstrates my practical skills in Git and GitHub version control. I created a `master` branch and committed a file that outputs a student's name. Then I branched off a `dev` branch and added a different output message. After that, I merged the `dev` branch back into `master` using a merge commit (with the -`-no-ff flag`) to preserve a clear history of the integration. Finally, I pushed the entire repository to GitHub. This workflow shows my ability to manage branches, perform merges, resolve potential conflicts, and publish code to a remote repository.
